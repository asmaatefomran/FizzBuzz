# FizzBuzz Detector

## Description
A C# application that replaces every third alphanumeric word with "Fizz", every fifth word with "Buzz", and every fifteenth word with "FizzBuzz".

## Features
- Processes alphanumeric words.
- Preserves punctuation and whitespace.
- Counts Fizz, Buzz, and FizzBuzz replacements.
- Includes unit tests using xUnit.

## Requirements
- .NET 8 SDK

## Run the Application

```bash
cd FizzBuzz
dotnet run
```

## Run Unit Tests

From the repository root:

```bash
dotnet test FizzBuzz.Tests/FizzBuzz.Tests.csproj
```
